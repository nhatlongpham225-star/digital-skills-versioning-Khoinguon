# digital-skills-versioning-Khoinguon
Khởi tạo dự án 
## 🎯 Mục tiêu dự án
Dự án này được tạo ra nhằm mục đích:
- Luyện tập các thao tác Git và GitHub cơ bản.
- Thử nghiệm quy trình commit, push, pull request và merge.
- Làm quen với cách tổ chức file và tài liệu trong một repository.

## 📂 Nguồn dữ liệu
- Dữ liệu giả lập được tạo thủ công (ví dụ: file CSV, JSON).
- Một số dữ liệu mẫu lấy từ các nguồn công khai như:
  - [Open Data](https://opendata.vn)
  - [Kaggle Datasets](https://www.kaggle.com/datasets) (chỉ dùng dữ liệu miễn phí và công khai)
- Không sử dụng dữ liệu nhạy cảm hoặc thông tin cá nhân.

- Python 3.x
